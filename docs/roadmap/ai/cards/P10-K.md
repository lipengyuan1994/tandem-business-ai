## Implementation decisions

- Compose maps empty/unset `DEMO_SITE_DOMAIN` to `(demo_site_disabled)`, which is an unused Caddy snippet.
  Caddyfile defaults to that snippet when the variable is absent. Caddy defaults alone do not handle an explicitly
  empty environment value. Native adaptation checks both modes and Compose resolution checks interpolation.
- CSP permits `https://<DOMAIN>` for the loader script, iframe and configuration fetch. Its style hash pins the
  loader's injected shadow-root stylesheet; it does not permit arbitrary inline styles or inline scripts.
  A deployment regression checks that the hash still matches the loader source. Main app policies are unchanged.
- The clinic disables microphone/camera/location. Missing files use an explicit 404 response so those responses
  also remove Server. Preserve the existing global prohibition on `handle_errors`: sites share Caddy listeners
  and upstream/capability errors must remain visible in the masked error log. Unexpected internal-error headers
  remain unverified; the existing Caddy error-response Server-header limitation is not claimed fixed here.
- The owner reports the live origin already allowed; this task does not query or change the VM or reset its data.
- This is deterministic static/deployment work; no semantic model calls are needed.
