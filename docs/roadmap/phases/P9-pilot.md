| ID | Task | Owner |

| P9-04 | Data import (customers, products, stock) through a CSV importer (new task, Tier B) | Tier B |
| P9-05 | Support process: contact channel, response targets, incident runbook drills, monthly restore drill | Owner |
| P9-06 | Measure the success measures in [01](../01-product-and-scope.md#success-measures-measured-never-promised) monthly; adjust prompts and routes with evals | Owner + Tier A |
| P9-07 | Decide distribution: Vultr Marketplace app, public images, pricing | Owner |
