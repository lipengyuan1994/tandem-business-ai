# Security re-scan, local half, 2026-11-03

**Scope and honesty.** A second run of the local half of the security pass (task P6-06) on the working tree of 1 November 2026 (there are no commits yet; the images are `smb/*:0.1.0-rc2` built that day; database head `20261031_1200_purchasing_quotes`). Same method as [the 26 October review](2026-11-local-review.md): the production images and `compose.prod.yml` on one machine (`make rehearse` with `--keep`), reached at `https://localhost:8443`. New since then: sales (quotes, orders, invoices, payment reminders), purchasing and procurement quotes with the public supplier page `/q/<token>` and `/api/v1/public/quotes/*`, the staff "Copy link" endpoint, SMTP e-mail, consent records from public chat, the regulated data profile, and platform changes (non-transactional jobs, per-business crons, an HTTP client that can reach configured local model hosts). AI features still do not exist and were not in scope.

This is **not** the roadmap's full pass and not an external audit: it was done by one agent with scanners and `curl` on a laptop. Still open: the scan of the public demo URL after deployment, a scan from another host over IPv4 and IPv6, an authenticated and an active ZAP scan, a person's review (list at the end). One planned step was **not run**: `pip-audit`. The session's permission classifier refused to run it through `uvx` (it is external code that is not part of the project), so it needs the owner's approval; an earlier `uvx pip-audit --version` had already put the tool into uv's cache. `trivy fs backend/uv.lock` was run instead and is a substitute, not the same check.
